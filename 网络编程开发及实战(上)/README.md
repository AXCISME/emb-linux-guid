## 目录结构

```
网络编程开发及实战(上)/
├─ README.md                        本说明

├─ asr/                             ASR 逐字稿（按小节分目录，保留原始识别结果与时间戳）
│   └─ 第NN节_xxx/

│       ├─ v02_视频名.txt
│       └─ 全文.txt                  本小节所有视频的合并稿
├─ screenshots/                     课程原片截图（按小节/视频分目录）
│   └─ 第NN节_xxx/
```

> Word 与 Markdown 是同一份稿子的两种格式，正文、表格、代码、图片完全对应；需要单节打印/分享时取 `word/`，需要检索/改稿时用 `教程/`，通读用最外层的全书。

## 素材说明

- **ASR**：faster-whisper medium 模型转写，保留同音错字（如“城域网”识别为“成域网”），教程正文已按上下文校正；引用原话时请以视频为准。
- **截图**：播放器区域 2 倍分辨率截图，每 10 秒内容一张，文件名即内容时间。部分小节的前几帧为课程片头/环境准备，可按需跳过。
- **教程**：按知识结构重排，不按视频时间顺序；每个重点配课程原片截图，并用“补充”“纠错”“易错点”标注老师口头带过或 ASR 识别错误的内容。
- 截图右下角带课程平台水印，**仅供个人学习使用，请勿外传**。

## 统计

- 逐字稿：36 个视频文件（另含 13 份小节合并稿），约 6000 行、47 万字符；
- 截图：2600 张（每 10 秒一张，按小节/视频归档；已用感知哈希去除 648 张内容重复帧）；
- 教程：13 节正文 + 课程导论，`教程/` 为 Markdown、`word/` 为同内容 Word，另有最外层的《全书.docx》。

## 使用建议

1. **第一遍**：按 01→13 顺序阅读 `教程/`，重点看每节的“学习目标”“小结与自测”。
2. **写代码**：直接看 06～09，对照 API 调用顺序与完整示例；遇到 `bind` 失败、`accept` 阻塞再回看 10～12。
3. **调试**：用 11、12 的抓包与包头字段，配合 Wireshark 逐字段对照。
4. **复习/面试**：看每节“易错点”和自测题；02、10、11 是高频考点。
5. **核对原片**：ASR 文件带时间戳，截图文件名即秒数，可直接跳转到视频对应位置。

## 生成方式

本套资料由 `video-note-kit` 工作流生成：3× 倍速播放一次，同时录制音频（48kHz）、按 10 秒截屏；音频按 120 秒内容分块，用 faster-whisper（GPU，medium 模型）增量转写；最后按知识点重排、配图、校正，生成 Markdown 并转换为 Word。
